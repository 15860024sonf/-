# 《城市疾走：Neon Runner》

**Neon Runner** 是一款以未來霓虹城市為背景的原創 2D 無盡跑酷遊戲。扮演穿梭街區的快遞員，在三條道路間閃避障礙、收集能量幣，挑戰更高分數與更高熱度。

## 遊戲玩法

在左、中、右三條道路間移動，避開迎面而來的路障、自動駕駛車與雷射門。路障可跳過，雷射門需滑行，自動駕駛車則要換道。收集金幣與道具，盡可能長時間生存。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| ← / → | 切換道路 |
| ↑ / Space | 跳躍 |
| ↓ | 滑行 |
| P / Esc | 暫停或繼續 |
| 手機左右滑動 | 切換道路 |
| 手機上滑 / 下滑 | 跳躍 / 滑行 |
| 畫面觸控按鈕 | 左移、右移、跳躍、滑行 |

## 遊戲特色

- Canvas 即時繪製城市、道路、角色、障礙物與特效，無需外部美術素材。
- 三種需要不同反應的障礙物，以及能量幣收集效果。
- 護盾可抵擋一次撞擊；磁力短時間吸引金幣；加速器提高速度與得分。
- 生存時間推升五階 Heat，逐步提高速度、障礙密度、金幣與分數倍率。
- 分數、金幣、生存時間、暫停、重新開始與 Game Over 結算。
- 最高紀錄使用瀏覽器 `localStorage` 保存。
- Web Audio API 合成簡單遊戲音效，沒有使用受版權保護的音樂或素材。
- 版面會依桌面、平板與手機尺寸調整。

## 使用技術

HTML5、CSS3、原生 JavaScript、Canvas API、Web Audio API、localStorage。沒有使用大型框架或外部套件。

## 如何在本機執行

1. 下載或 clone 專案。
2. 直接用瀏覽器開啟 `index.html` 即可遊玩。
3. 若瀏覽器限制本機檔案功能，也可以在專案目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。

## GitHub Pages 部署

1. 將專案推送到 GitHub repository。
2. 在 repository 的 **Settings → Pages** 選擇部署來源（例如 `Deploy from a branch`）。
3. 選擇 `main` 分支與 `/ (root)` 資料夾並儲存。
4. 等待 GitHub Pages 部署完成後，使用 Pages 提供的網址開啟遊戲。
